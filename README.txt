5월 25일 호우 대응 부처별 보도자료 정적 웹페이지

[실행 및 배포]
1. 압축파일을 해제합니다.
2. index.html을 더블클릭하면 인터넷 연결 없이 실행됩니다.
3. 웹 호스팅에 배포할 때에는 아래 4개 파일을 같은 폴더에 업로드합니다.
   - index.html
   - style.css
   - app.js
   - 데이터.js

[필수기능]
- 페이지 실행 시 데이터.js의 모든 보도자료 카드 표시
- 검색어 입력 시 제목/본문/부처에 포함된 자료만 실시간 표시
- 결과 수 표시

[추가 기능]
- 부처별 필터
- 보도자료 원문 전체 펼쳐보기/접기
- 검색 초기화
- 휴대전화 화면 대응

[주의]
- 데이터.js는 첨부된 스타터 데이터를 수정하지 않고 사용합니다.
- 부처별 통계 수치/시각의 상이함은 원문을 따라 유지합니다.
- 원문 열람에는 문자열 그대로 표시되므로 원문의 Markdown 기호가 일부 노출됩니다.
